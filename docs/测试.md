1. 准备工作

你需要一台电脑（macOS、Windows 或 Linux 均可），以及稳定的网络连接。

1.1 安装 Node.js

Claude Code 和 OpenClaw 都依赖 Node.js 22 或更高版本。

macOS / Linux：

打开终端（Terminal），粘贴以下命令回车：

curl -fsSL https://fnm.vercel.app/install | bash

安装完成后，关闭终端重新打开，然后运行：

fnm install 22
fnm use 22

Windows：

1. 访问 Node.js 官网，下载 LTS 版本（22.x）
2. 双击安装包，一路点「下一步」即可
3. 安装完成后，打开 PowerShell，输入 node -v 确认版本

安装后重启电脑，后续操作在 WSL2 的 Ubuntu 终端中进行，体验更好。

4. 配置 Claude Code 使用中转服务

这是最关键的一步——让 Claude Code 连接到我们的中转服务，而不是 Anthropic 官方 API。

方法一：环境变量配置（推荐）

macOS / Linux / WSL2：

编辑你的 shell 配置文件：

# 如果你用的是 zsh（macOS 默认）
nano ~/.zshrc

# 如果你用的是 bash
nano ~/.bashrc

在文件末尾添加以下两行：

export ANTHROPIC_BASE_URL="https://tokenmax.vip"
export ANTHROPIC_API_KEY="sk-你的API Key"

保存退出后，执行：

source ~/.zshrc  # 或 source ~/.bashrc

Windows PowerShell：

$env:ANTHROPIC_BASE_URL = "https://tokenmax.vip"
$env:ANTHROPIC_API_KEY = "sk-你的API Key"
设置后重新打开 PowerShell 生效。

Windows （通过setx命令）：
setx ANTHROPIC_BASE_URL "https://tokenmax.vip"
setx ANTHROPIC_API_KEY "你的 key"

方法二：Claude Code 设置文件

在终端中运行 claude 进入交互模式，然后输入 /config 打开设置，或者直接编辑配置文件：

创建/编辑 ~/.claude/settings.json：

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://tokenmax.vip",
    "ANTHROPIC_API_KEY": "sk-你的API Key"
  }
}

- Linux：下载 .deb（Ubuntu/Debian）、.rpm（Fedora）或 .AppImage（通用）
  
⚠️ macOS 首次打开可能提示"无法验证开发者"，请前往「系统设置」→「隐私与安全性」→ 点击「仍要打开」。

7.2 配置向导

安装完成后会自动进入配置向导（onboarding），按提示操作：

1. 选择 AI 提供商 → 选择 Anthropic
2. 输入 API Key → 粘贴你在 tokenmax.vip 获取的 API Key
3. 设置 Base URL → 输入 https://tokenmax.vip/v1  or https://tokenmax.vip
4. 选择模型 → 推荐选择 claude-sonnet-4-20250514（性价比最高）

openclaw configure

      "baseUrl": "https://tokenmax.vip/v1",
      "apiKey": "sk-你的API Key",
      "auth": "api-key",
      "authHeader": true,
    }
  }

Q: 安装时提示 command not found: claude 或 'claude' 不是内部或外部命令？

这是最常见的问题，说明 Claude Code 的安装路径没有加入系统 PATH。

macOS / Linux 解决方法：

# 检查 PATH 中是否包含安装目录
echo $PATH | tr ':' '\n' | grep local/bin

# 如果没有输出，添加到 shell 配置
# zsh 用户（macOS 默认）
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# bash 用户（Linux 默认）
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

Windows PowerShell 解决方法：

# 检查 PATH
$env:PATH -split ';' | Select-String 'local\\bin'

# 如果没有输出，添加到 PATH
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

添加后重新打开终端即可。

Q: 安装脚本报错 syntax error near unexpected token '<'？

这说明安装脚本下载到的是 HTML 页面而不是脚本内容，通常是网络问题。

解决方法：

1. 检查网络连接，确保能访问 Google Cloud Storage：
curl -sI https://storage.googleapis.com
2. 如果网络受限，使用替代安装方式：
# macOS
brew install --cask claude-code

# Windows
winget install Anthropic.ClaudeCode
3. 如果提示 "App unavailable in region"，说明你的 IP 所在地区不支持，请使用代理网络。

Q: 安装时提示 curl: (56) Failure writing output to destination？

下载过程中网络连接中断了。

解决方法：

1. 检查网络稳定性，重试安装命令
2. 或者先下载脚本再执行：
curl -fsSL https://claude.ai/install.sh -o install.sh
bash install.sh

Q: 安装时报 TLS / SSL 错误？

常见错误信息：TLS connect error、SSL/TLS secure channel、unable to get local issuer certificate

解决方法：

# Ubuntu/Debian 更新证书
sudo apt-get update && sudo apt-get install ca-certificates

# macOS 更新证书
brew install ca-certificates

Windows 用户在 PowerShell 中先执行：

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

然后重新运行安装命令。

Q: Linux 服务器安装时被 Killed？

系统内存不足，被 OOM Killer 终止了。Claude Code 安装至少需要 4GB 内存。

解决方法 — 添加 Swap 空间：

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

然后重新安装。

Q: 报错 401 Unauthorized 或 Authentication failed？

API Key 认证失败。

排查步骤：

1. 确认 API Key 复制完整，前后没有多余空格
2. 确认环境变量设置正确：
echo $ANTHROPIC_API_KEY
echo $ANTHROPIC_BASE_URL
3. 确认 Base URL 是 https://tokenmax.vip（注意是 https，不要漏掉 s）
4. 登录 https://tokenmax.vip 检查账户余额是否充足
5. 检查 API Key 是否已过期或被禁用
  

---

Q: 报错 Connection timeout 或 ECONNREFUSED？

无法连接到中转服务。

排查步骤：

1. 检查网络是否正常：
curl -sI https://tokenmax.vip
2. 如果你在公司网络，可能需要设置代理：
export HTTPS_PROXY=http://你的代理地址:端口
3. 检查防火墙是否拦截了 HTTPS 请求
  

---

Q: 报错 429 Too Many Requests 或 Rate limit exceeded？

请求频率超过限制。

解决方法：

1. 等待几秒后重试，Claude Code 会自动重试
2. 减少并发使用的 Claude Code 实例数量
3. 如果频繁遇到，联系客服提升速率限制
  

---

Q: 报错 overloaded_error 或 503 Service Unavailable？

上游 Claude API 暂时过载。

解决方法：

1. 等待 1-2 分钟后重试
2. 这是 Anthropic 服务端的临时问题，通常很快恢复
3. 如果持续出现，可以切换到其他模型试试：在 Claude Code 中输入 /model

Q: Claude Code 可以做什么？

- 阅读和理解整个代码库
- 编写、修改、删除代码文件
- 执行终端命令（编译、测试、Git 操作等）
- 创建 Git commit、分支、Pull Request
- 修复 Bug、写测试、重构代码
- 解释代码逻辑、回答技术问题

Q: Claude Code 修改了我的文件，怎么撤销？

Claude Code 的每次修改都可以撤销：

1. 按 Ctrl+Z（在 Claude Code 交互界面中）可以撤销上一步操作
2. 如果已经退出，用 Git 恢复：
git diff           # 查看改动
git checkout .     # 撤销所有未提交的改动
  
💡 建议在让 Claude Code 做大改动前先 git commit，这样随时可以回退。

Q: 如何让 Claude Code 不要自动执行命令？

Claude Code 默认会在执行命令前询问你。如果你想更严格地控制：

在 ~/.claude/settings.json 中设置：

{
  "permissions": {
    "allow": [],
    "deny": ["Bash(*)", "Computer(*)"]
  }
}

这样每次执行命令都会先征求你的同意。

Q: VS Code 插件安装后找不到？

1. 按 Cmd+Shift+P（macOS）或 Ctrl+Shift+P（Windows/Linux）
2. 输入 Claude Code
3. 选择 Claude Code: Open in New Tab
  
如果搜索不到，确认插件已安装：按 Cmd+Shift+X 打开扩展面板，搜索 "Claude Code" 确认状态为「已安装」。


---

Q: VS Code 插件提示连接失败？

1. 先确认终端版 Claude Code 能正常使用（排除 API Key 和网络问题）
2. 检查 VS Code 的 settings.json 中环境变量是否正确
3. 重启 VS Code
4. 如果仍然不行，卸载插件重新安装

OpenClaw 相关

Q: openclaw 命令找不到？

# 检查 npm 全局安装路径
npm prefix -g

# 确保该路径的 bin 目录在 PATH 中
export PATH="$(npm prefix -g)/bin:$PATH"

添加到 ~/.zshrc 或 ~/.bashrc 中使其永久生效。


---

Q: OpenClaw 启动失败？

# 运行诊断
openclaw doctor

# 查看详细日志
openclaw gateway logs

# 重启 Gateway
openclaw gateway restart

Q: OpenClaw 如何配置使用我们的中转服务？

在配置向导中选择 Anthropic 提供商，输入 API Key 和 Base URL。或者直接编辑配置：

openclaw configure

选择 Anthropic → 输入 API Key → 输入 Base URL https://tokenmax.vip
