# 故实巡礼 · 选书推荐 Prompt（带记忆系统）

> **核心设计**: 每次调用时将「已选书目 + 覆盖统计 + 空白区域」注入 prompt，
> 让 AI 自动避免重复推荐并主动填充空白覆盖区域。

---

## 系统 Prompt（System Message）

```
你是「故实巡礼」(Geolore) 的选题编辑 AI。

故实巡礼是一款将文学作品中的地点提取为地理坐标、让用户在现实世界中"巡礼"的应用。
你的任务是推荐最适合被"地理化"的书籍——那些天然带有空间坐标基因、
且能通过地理位置产生阅读增量价值的内容。

你必须严格遵循以下原则：
1. 绝不推荐已在记忆清单中的书籍
2. 主动填充覆盖空白（未覆盖的地区和类型优先）
3. 中英文作品兼收，优先选择受众广泛的
4. 每部作品必须通过选题价值边界评估
```

## 使用方式

### 方式一：选书侦察模式（推荐）🆕

```bash
# 选书侦察模式：推荐 20 本，每轮 5 本，共 4 轮 API 调用，附地图价值排名
python scripts/recommend_books.py --mode scout --count 20

# 选书侦察 + 偏好地区和类型
python scripts/recommend_books.py --mode scout --count 15 --prefer-region "日本,欧洲" --prefer-type "travelogue"

# 选书侦察 + 自定义每轮数量
python scripts/recommend_books.py --mode scout --count 30 --batch-size 5

# 只打印 prompt 不调用 API（手动使用）
python scripts/recommend_books.py --mode scout --count 20 --dump-prompt
```

选书侦察模式特点：
- **多轮 API 调用**：每轮只处理 5 本，保证质量
- **记忆递增**：每轮结果立即写入注册表，下一轮 AI 看到更完整的记忆
- **自动排名**：全部完成后按地图价值综合评分排名
- **容错机制**：某轮失败不影响后续轮次

### 方式二：单次推荐模式

```bash
# 推荐 5 本新书（自动注入记忆）
python scripts/recommend_books.py --count 5

# 推荐 10 本，指定偏好
python scripts/recommend_books.py --count 10 --prefer-region "日本,欧洲" --prefer-type "travelogue"

# 查看当前注册表状态
python scripts/recommend_books.py --status
```

### 方式二：手动使用

1. 运行 `python scripts/recommend_books.py --dump-prompt --count 5`
2. 复制输出的完整 prompt
3. 粘贴到你的 AI 聊天窗口
4. 将 AI 的 JSON 输出保存，再运行 `python scripts/recommend_books.py --import result.json`

## 记忆系统工作原理

```
  ┌──────────────────────────────────────────┐
  │  registry.json （持久化记忆）              │
  │                                           │
  │  books: [                                 │
  │    { title, author, grade, region, ... }, │
  │    { title, author, grade, region, ... }, │
  │    ...                                    │
  │  ]                                        │
  │  stats: { by_region, by_type, ... }       │
  └────────────┬─────────────────────────────┘
               │ 每次推荐时读取
               ↓
  ┌──────────────────────────────────────────┐
  │  build_memory_block()                     │
  │                                           │
  │  → 已有书目清单                            │
  │  → 覆盖统计（地区/类型/语言）               │
  │  → 空白区域提示                            │
  │  → 排除列表                               │
  └────────────┬─────────────────────────────┘
               │ 注入到 prompt
               ↓
  ┌──────────────────────────────────────────┐
  │  LLM Prompt                               │
  │                                           │
  │  "已有 23 部书...                          │
  │   未覆盖：日本/欧洲/travelogue             │
  │   严禁推荐：《繁花》《文化苦旅》..."         │
  └────────────┬─────────────────────────────┘
               │ AI 生成
               ↓
  ┌──────────────────────────────────────────┐
  │  新推荐结果 → 追加到 registry.json         │
  └──────────────────────────────────────────┘
```

每次循环，AI 看到的"记忆"越来越长，覆盖越来越全面，
推荐的多样性自然提升，重复风险趋近于零。
